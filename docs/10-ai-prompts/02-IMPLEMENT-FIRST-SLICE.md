# Prompt 02 — Construção da primeira vertical slice

Implemente **somente** a primeira vertical slice aprovada: Next.js + TypeScript, PostgreSQL, autenticação configurável e CRUD de programa/domínio/frente/capacidade/entregável, vínculo N:N, Capability Map com filtros e drill-down. Use os documentos como fonte normativa.

Entregue:
- código organizado em módulos, migrations e seed fictício;
- API versionada, validação, erros e RBAC;
- UI baseada na direção visual **nova e aprovada**;
- testes unitários, integração, contrato e e2e smoke;
- Docker Compose, `.env.example`, README de execução;
- checklist DoD e relatório de limitações.

Não simule persistência com localStorage em telas de produção; mocks apenas no modo demo explicitamente marcado. Não declare testes executados sem evidência.
