# Personas, jornadas e perguntas de negócio

## Arquiteto geral
**Pergunta:** quais lacunas transversais impedem entregar uma capacidade? **Jornada:** Overview → Capability Map → célula camada → entregáveis → contratos/fornecedores → dependências → gate/decisão → registrar ação.

## Líder de frente
**Pergunta:** o que devo atualizar e destravar esta semana? **Jornada:** My Workstream → entregáveis vencendo/sem update → status e forecast → impedimento → impacto → publicar atualização.

## Executivo
**Pergunta:** estamos avançando com confiança? **Jornada:** Executive Overview → tendência vs baseline → saúde por frente → top riscos → decisões pendentes → relatório semanal.

## PMO
**Pergunta:** o que mudou na previsão e escopo desde a última baseline? **Jornada:** Baseline Comparison → change log → marcos → dependências → snapshot → report.

## Aprovador de gate
**Pergunta:** posso autorizar a passagem de estágio? **Jornada:** Readiness Queue → evidências → critérios → aprovar/reprovar/exceção → auditoria.

## Regras de UX para jornadas
Em qualquer visão agregada, permitir drill-down até registros; exibir data de atualização, proveniência, completude do inventário e explicação do cálculo.
